# Manuscript Formatter

Wraps a narrative draft, figure specs, and tables into a structured manuscript payload. The output is markdown-first so it remains diffable and bundle-friendly.

Supported `target_style` values:

- `generic-journal`
- `prisma-systematic-review`
- `apa-7`
- `nature-portfolio`

The module adds required section scaffolding, title-page metadata, an asset inventory, and a submission checklist. It intentionally marks final editorial review as required; journal-specific upload portals and copyediting remain human-controlled.
